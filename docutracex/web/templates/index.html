Settings

          
        

        
Network — proxy

        
Every network feature of DocuTraceX (checking URLs, domains and IPs from the IOCs) goes through this proxy. The installer and the updater never use it. Credentials are stored in plain text in config/settings.json on this machine.

        

          
          

            
            
            
            
            
          

          

            
            
            
          

        

        
Network — free public proxy

        
Pick a working proxy from the ProxyScrape free list (downloaded at startup, refreshed daily): random candidates are tested in parallel and the first that answers a strictly verified HTTPS request becomes the proxy above. Free proxies are untrusted: checks through them never accept an invalid certificate (so they can't inject content into the evidence) and are labelled "free proxy". They die often — a dead one is replaced automatically before the next check. Kits sometimes block public proxy IPs: if a page looks clean, re-check after rotating.

        

          
          
        

        

          
          
          
        

        


        
Network — without a proxy

        

        
How URLs are checked

        
    
          
  • Only when you press Check; nothing goes out on its own.
    • 
          
  • Requests look like a real browser (Edge on Windows and Safari on iPhone, with their headers); both views are compared to detect cloaking.
    • 
          
  • The victim's address in the link (plain, URL-encoded or Base64) is replaced by a random fake identity on mail.com / gmx.com / email.com / post.com / consultant.com / usa.com.
    • 
          
  • No JavaScript runs and no images/CSS are loaded; inline scripts go through the isolated V8 sandbox. Forms are only sent when you press Send fake credentials.
    • 
          
  • Files served by the URL are analysed as nested children of the case.
    •

Registry: Sigma rules

        
A folder on this machine with Sigma rules (a clone of
          SigmaHQ, your own rules, or both;
          searched recursively). Its registry rules (registry_set / _add /
          _delete / _event) run on every hive and .reg of a case; nothing is
          downloaded. A rule that cannot be translated faithfully is skipped and listed below with why. Sigma rules describe
          changes: on a hive every match is a value that exists, Windows defaults included — the last-write time tells how recent.

        

          
          

        

        

        
Generic legitimate domains

        
Well-known providers that are never reported as look-alikes of your domains or brands
          (outlook.office.com is Microsoft's), without listing them as own domains or brands — one per line.
          Services: the whole domain is the provider's, never compared. Platforms: anyone picks the subdomain,
          so only the tenant part is compared (micros0ft-login.onmicrosoft.com is still reported).
          Only the look-alike checks use these lists: every other rule still judges these domains.
